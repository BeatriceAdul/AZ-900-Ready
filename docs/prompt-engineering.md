# AZ-900 Ready — Prompt Engineering

## 1. Overview

Prompt engineering is used in AZ-900 Ready to define how an AI Study Buddy should respond to learners.

The goal is not simply to generate answers.

The goal is to produce responses that are:

- Accurate
- Beginner-friendly
- Clear
- Useful for learning
- Focused on the learner's question

The Study Buddy should help learners understand concepts rather than simply provide answers.

---

# 2. AI Study Buddy Goal

The AI Study Buddy is designed to help a beginner understand cloud and Azure concepts.

A learner should be able to ask questions such as:

- "What is scalability?"
- "What is the difference between IaaS and PaaS?"
- "Explain Azure regions simply."
- "What is a resource group?"
- "Why do we use availability zones?"

The response should be understandable to someone who is new to cloud computing.

---

# 3. Prompt Structure

A useful Study Buddy prompt can be structured as:

```text
Role
+
Learning objective
+
Learner question
+
Learner level
+
Response requirements
```
